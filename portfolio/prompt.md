# 입시 학원 홍보 홈페이지 제작 프롬프트

너는 웹페이지 개발자이자 UI/UX 전문가야.
아래 6개 섹션으로 구성된 입시 학원 홍보 홈페이지를 단일 HTML 파일로 만들어줘.

---

## 전체 공통 조건

- 스크롤 시 섹션 단위로 전환: `scroll-snap-type: y mandatory`, 각 섹션 `height: 100vh`
- 우측 고정 네비게이션 dot: 현재 섹션 표시, 클릭 시 해당 섹션으로 이동
- CSS는 섹션별 ID(`#s1` ~ `#s6`)로 완전히 격리해줘 — 섹션끼리 스타일이 절대 섞이면 안 돼
- 이미지가 필요한 자리는 배경색 블록으로 대체하고 alt 텍스트만 표시
- 모든 텍스트 내용은 입시 학원 홍보에 맞게 작성
- Google Fonts에서 필요한 폰트 모두 불러와줘
- 단일 HTML 파일로 완성 (CSS·JS 전부 인라인)

## SECTION 1 — 학원 소개 히어로

**래퍼런스: matplaza.com**

### 핵심 특징
- 배경: 순백 `#ffffff`
- 학원 이름을 페이지 너비를 꽉 채우는 초대형 블랙 타이포로 배치 (Bebas Neue 또는 Unbounded, 검정, vw 단위로 화면 꽉 차게)
- 텍스트 레이어 위에 정사각형에 가까운 이미지 블록이 중앙에 오버랩되어 글자를 가리는 구조
- 상단 헤더: 좌측 `MENU`, 중앙 학원명 + 카피라이트, 우측 `KOR ENG` — 모두 작은 크기, 흑백
- 하단: 좌측에 학원 소개 한 줄 문구, 하단 바에 영문 키워드 3개를 양 끝과 중앙에 배치 (border-top 1px)

### 레이아웃 구조
```
┌─ 헤더 ──────────────────────────────────────────────┐
│  MENU        ©학원명 All rights reserved    KOR ENG  │
└─────────────────────────────────────────────────────┘

  [초대형 학원명 타이포 — 화면 너비 꽉 채움]
       위에 정사각 이미지 블록이 중앙 오버랩

  학원을 한 줄로 소개하는 문구
─────────────────────────────────────────────────────
  최상위권 입시 전문         명문대 합격의 시작         SOLUTIONS
```

### 스타일 스펙
```
배경:            #ffffff
학원명 타이포:   Bebas Neue 또는 Unbounded, font-size: 20vw 이상, color: #111, letter-spacing: -0.02em
이미지 오버랩:   position absolute, 중앙, width ~40vw, aspect-ratio 3/4, z-index: 2
헤더 폰트:       sans-serif, 12~13px, color: #111
하단 바:         border-top: 1px solid #111, font-size: 11~12px, letter-spacing: 0.1em, uppercase
```

## SECTION 2 — 학원 특징 / 프로그램 소개

**래퍼런스: gihoo.or.kr**

### 핵심 특징
- 배경: 밝고 부드러운 하늘색 `#e8f4fd` 또는 `#d6eeff`
- 메인 헤드라인: 굵고 둥근 느낌의 한글 폰트, 파란 계열 + 녹색 계열 투톤 컬러 적용 (두 줄)
- 서브 텍스트: 녹색 계열로 강조, 느낌표 포함한 짧고 임팩트 있는 문구
- 우측에 3D 캐릭터 이미지 (→ 컬러 일러스트 이미지 블록으로 대체)
- 배경에 원형 버블 장식 요소 여러 개 (투명한 흰 원, 다양한 크기)
- 좌측 상단에 작은 3D 아이콘들 (→ 이모지로 대체 가능)
- 상단 GNB: 흰 배경, 학원명 로고, 메뉴 (수업소개, 커리큘럼, 수강후기, 이벤트)

### 레이아웃 구조
```
┌─ GNB (흰 배경) ─────────────────────────────────────┐
│  [학원 로고]    수업소개   커리큘럼   수강후기   이벤트│
└─────────────────────────────────────────────────────┘

배경: 하늘색
  📚 (좌상단 아이콘)           🏆 (우상단)

  ┌── 좌측 텍스트 ──────────────────┐
  │  초대형 한글 헤드라인 (2줄)      │        [3D 캐릭터
  │  (파랑+녹색 투톤 컬러)           │         이미지 블록]
  │                                 │
  │  서브 강조 문구 (녹색, 느낌표)   │
  └─────────────────────────────────┘

  ⭕ 버블 장식들 (배경에 반투명)       🗑 (좌하단 아이콘)
```

### 스타일 스펙
```
배경:            #d6eeff ~ #e8f4fd (하늘색 계열)
헤드라인 폰트:   Noto Sans KR 900, font-size: clamp(44px, 7vw, 80px), line-height: 1.2
헤드라인 색:     첫 줄 #1565c0 (파랑), 둘째 줄 #111 또는 #1565c0
서브 텍스트:     color: #2e7d32 (녹색), font-weight: 800, font-size: clamp(24px, 4vw, 40px)
버블 장식:       border-radius: 50%, background: rgba(255,255,255,0.4), position: absolute
GNB 배경:       #ffffff, border-bottom: 1px solid #eee
```

## SECTION 3 — 강사진 / 콘텐츠 카드

**래퍼런스: gsartscenter.com**

### 핵심 특징
- 배경: 순백 `#ffffff`
- 상단 GNB: 좌측 학원 로고(파이프 기호 포함, `|학원명|`), 메뉴 텍스트, 우측 아이콘들
- 본문: 4컬럼 카드 그리드 (이미지 + 카테고리 텍스트 + 제목 + 날짜)
  - 1번 카드: 세로로 길고 어두운 배경 이미지 카드 (타이포 오버레이)
  - 2번 카드: 직사각형 이미지 (세로로 더 김)
  - 3~4번 카드: 정사각형에 가까운 이미지 + 하단 텍스트
- 카드 아래 구분선 + `VIEW ALL` 버튼 (전체 너비, border)
- 하단 푸터: 학원 주소/연락처 / 링크 목록 / 뉴스레터 구독 인풋

│  |학원명|    수업안내   강사소개   공간소개      👤 🔍 ENG ≡  │
└─────────────────────────────────────────────────────────────┘

  ┌────────┬────────┬────────┬────────┐
  │[이미지]│[이미지]│[이미지]│[이미지]│  ← 4컬럼, 높이 다름
  │ 어두운 │ 세로로 │        │        │
  │ 텍스트 │  길게  │        │        │
  │ 오버랩 │        │        │        │
  ├────────┴────────┴────────┴────────┤
  │  카테고리 (회색 소문자)            │
  │  **카드 제목** (굵게)              │
  │  날짜                              │
  └────────────────────────────────────┘

  ┌──────────────── VIEW ALL ──────────────────┐
  └────────────────────────────────────────────┘

─────────────────────────────────────────────────────
  학원명          공지사항          NEWSLETTER
  주소            수업안내          [이메일 입력] [등록]

## SECTION 4 — 합격 실적 / 수치 강조

**래퍼런스: withyoulove.co.kr**

### 핵심 특징
- 배경: 순백 `#ffffff`
- 레이아웃: 좌측 텍스트 영역 + 우측 일러스트/이미지 영역 (약 1:1 비율)
- 좌측 상단에 작은 컬러 레이블 태그 (녹색 또는 포인트 컬러, 소형 텍스트)
- 좌측 메인 헤드라인: Noto Sans KR 또는 한글 고딕, 매우 굵게 (900), 검정, 2줄

  │           학원의 비전 슬로건 2줄                 │

## SECTION 6 — 상담 신청 (필수)

**래퍼런스: flyq.co.kr**

### 핵심 특징
- 배경: 밝은 회색 `#f0f0f0` 또는 `#e8e8e8`
- 상단 GNB: 중앙 학원명 로고, 우측에 `+ 오시는 길`, `+ 상담 신청` 텍스트 링크
- GNB 아래 탭 UI: 탭 여러 개 (각기 다른 파스텔 배경색), 선택된 탭은 흰 배경 + 상단 뾰족한 탭 모양
- 탭 내용 영역: 좌측 이미지 블록 + 우측 수치/텍스트 리스트 구조

  - 좌측 이미지: 흰 테두리 border, 약간의 shadow
- 하단 푸터 바: 회색 바, 학원 관련 기관 로고들 나열, 우측 전화번호 크게 표시
- 우측에 세로 회전 텍스트 (학원 슬로건, 90도 회전)

### 폼 포함 조건
```
탭 중 하나("상담신청" 탭)를 클릭하면 아래 폼이 탭 콘텐츠 영역에 표시:

필드:
  - 이름 (필수)
  - 연락처 (필수)
  - 관심 과정 select (수시/정시/논술/면접/기타)
  - 문의사항 textarea

버튼: "상담 신청하기" — flyq 스타일에 맞게 심플하고 각진 디자인
제출 시: 유효성 검사(이름+연락처) → 완료 메시지 표시
```

### 스타일 스펙
```
배경:            #efefef 또는 #e8e8e8
GNB 배경:        #f5f5f5, border-bottom: 1px solid #ddd
GNB 로고:        font-family: 세리프 계열, font-size: 20px, letter-spacing: 0.1em, color: #111
탭 배경색:       흰/하늘/분홍/연두/노랑/회색 — 각각 다른 파스텔
탭 폰트:         Noto Sans KR, 13~14px, color: #333
수치 숫자:       font-weight: 900, font-size: clamp(32px, 5vw, 64px), color: #111, letter-spacing: -0.02em
수치 설명:       font-size: 12~13px, color: #666
수치 구분선:     border-bottom: 1px solid #ccc, padding-bottom: 20px, margin-bottom: 20px
세로 회전 텍스트: writing-mode: vertical-rl, font-size: 11px, letter-spacing: 0.2em, color: #999
푸터 바:         background: #ddd, padding: 12px 40px, display: flex, justify-content: space-between
전화번호:        font-weight: 900, font-size: 20px, color: #111
```
